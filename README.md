# DevNetwork | Tela 2 — Perfil

Tela de perfil da DevNetwork, uma rede social para desenvolvedores simulada
em um projeto em grupo da disciplina Desenvolvimento Front-End para Web.

## Minha contribuição

Desenvolvi a página de perfil com apresentação do desenvolvedor, tecnologias,
projetos, experiência e atalhos para outras áreas do site. Usei HTML5 para
estruturar a página e CSS3 para criar os cartões e o layout responsivo.

## Como visualizar

Baixe `pag2.html` e `pag2.css` na mesma pasta e abra `pag2.html` no navegador.
Os dados são demonstrativos. Os links para outras telas dependem da versão
integrada.
